# HANDLINK Google Play 스토어 등록 자료

## 간단한 설명

원을 움직여 다가오는 적을 정확히 막아내는 감각형 아케이드 게임.

## 자세한 설명

손끝으로 원을 움직여 중심을 지키세요.

HANDLINK는 단순한 조작과 정확한 판단이 만드는 아케이드 게임입니다. 다가오는 적을 알맞은 타이밍과 거리에서 막아내고, 더 높은 점수에 도전하세요.

플레이하면서 획득한 코인으로 판정 범위, 추가 생명, 최대 스태미나, 원 크기를 강화할 수 있습니다. 나만의 플레이 스타일에 맞춰 성장시키고 최고 기록을 갱신해 보세요.

주요 특징

- 손가락으로 원을 직접 움직이는 직관적인 조작
- 정확한 거리 판단으로 완성하는 긴장감 있는 플레이
- 스태미나를 고려한 전략적인 움직임
- 코인을 모아 판정 범위, 생명, 스태미나, 원 크기 강화
- 언제든 설정에서 다시 볼 수 있는 튜토리얼

## 이미지 파일

- `app-icon-512.png`: Google Play 앱 아이콘 (512 x 512, 실제 런처 아이콘 원본 사용)
- `feature-graphic-1024x500.png`: 피처 그래픽 (1024 x 500, 실제 인게임 화면 사용)
- `phone/`: 휴대폰용 스크린샷 2장 (1440 x 2560, 9:16)
- `tablet/`: 태블릿용 스크린샷 2장 (1440 x 2560, 9:16)

모든 이미지는 프로젝트에 있던 실제 아이콘 및 인게임 스크린샷으로만 제작했습니다.
